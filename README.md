# MIA Computational Assessment

Computational analysis of the monoterpene indole alkaloid (MIA) biosynthetic pathway in *Catharanthus roseus*.

This repository contains the scripts, sequence data, alignments, figures, and processed results used to evaluate:

- RetroPath2.0 recovery of known MIA pathway transformations
- Experimental characterization of pathway enzymes
- Protein homology and sequence conservation
- Integrated pathway-level computational tractability

## Repository structure

- `scripts/` — Python analysis scripts
- `data/` — processed benchmark and homology data
- `sequences/` — protein FASTA sequences
- `alignments/` — multiple-sequence alignment files
- `blast_batches/` — BLAST batch input/output files
- `figures/` — figures used in the analysis

## Main results

RetroPath recovered 15 of 21 evaluable transformations (71.4%).  
Seven transformations produced technical errors.  
Twenty-nine enzymes were assessed, with 9 classified as well-characterized and 20 as partially characterized.
